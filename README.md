## Vinheria Agnello Checkpoint03

O projeto conta com um sistema de estoque de vinhos, nesse sistema o usuário deve cadastrar os vinhos através do prompt no Navegador e todos os outputs serão exibidos no Console Log, o sistema apresenta todos os Vinhos cadastrados, avisa o usuário sobre baixo estoque, exibe o total do estoque, assim como o total de vinhos.
